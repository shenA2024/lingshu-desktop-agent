备份与恢复

在「设置 → 通用 → 数据备份」下载 ZIP。请先完成或停止正在运行的对话与实验。

保存哪些内容

备份保存应用中的对话、工具记录、完整实验轨迹和记忆笔记，并附文件摘要。它包含你的对话内容，请作为个人数据保存。

模型密钥、账号凭据、Harness 原始会话与推理日志、依赖缓存和浏览器外观偏好不包含在内。

恢复到新目录

在灵枢目录打开 PowerShell，用已安装依赖的 Python 执行：

.\.venv\Scripts\python.exe -X utf8 .\data_backup.py "备份.zip" --destination "D:\灵枢恢复数据"

目标目录必须尚不存在。恢复会核对文件清单和摘要，已有数据不会被覆盖。恢复后，在另一个未占用的端口启动查看：

$env:LINGSHU_WORKBENCH_DATA = 'D:\灵枢恢复数据'
$env:LINGSHU_WORKBENCH_PORT = '8799'
.\.venv\Scripts\python.exe -X utf8 .\workbench.py

打开 http://127.0.0.1:8799。用 Ctrl+C 停止该实例。

恢复后的对话

对话历史可以查看、搜索、重命名和导出。由于原始 Harness 会话未备份，恢复的历史记录为只读；继续工作请新建对话。实验轨迹可以回放，记忆笔记可以召回。模型凭据需要在本机重新配置或沿用本机 Harness 配置。

如已安装到其他 Python 环境，请将上述 Python 路径替换为实际路径。
