# 通用工具接入

在「连接管理 → 通用工具 · MCP」添加服务，保存后点击「检查连接」。检查会实际启动本机服务或访问 HTTP 服务，完成 MCP 初始化并读取工具列表。成功后可启用；下一轮对话使用已启用的连接。编辑配置后会停用并要求重新检查。运行中的对话继续使用本轮的固定配置，修改设置需先结束运行中的对话。

## 本机进程

选择 stdio，填写可执行文件和参数。每行一个参数，应用直接启动进程，不使用 shell 字符串。例如：

```text
命令：C:\Python313\python.exe
参数：
-m
your_mcp_server
```

可指定工作目录。使用服务要求的环境变量时，在「环境变量」添加名称和值。应用不自动下载或安装服务器；请先按该服务器的文档安装。

## HTTP

选择 Streamable HTTP，填写如 `http://127.0.0.1:3000/mcp` 的实际地址。需要认证时在标头添加如 `Authorization` 和 `Bearer <你的令牌>`。URL 不接受用户名、密码、查询参数或 fragment，凭据放在标头中。此版本不支持旧的独立 SSE transport、OAuth 登录流程或 MCP prompts/resources。

## 凭据与生命周期

环境变量与标头值由 Windows 用户级 DPAPI 加密保存。返回浏览器的配置只有字段名称；编辑时留空保留已有值，删除一行会删除该字段。关闭设置对话框会清空密码输入。请勿将密钥写在命令、参数或地址中。

公开配置和保护后的凭据均位于 `data/agent/`，不进入 Git、体验包或可见数据备份。数据备份含聊天中可见的工具参数与结果；外部服务返回的数据属于对话内容，请按自己的数据需要保管备份。

检查有 20 秒时限；工具请求有 60 秒时限；对话轮次沿用 10 分钟上限。本机进程由连接检查或对话进程树拥有，结束、取消或超时后清理。HTTP 服务端的远程任务是否能停止，取决于服务是否响应取消与断开。

运行时使用已验证的 Harness 0.2.0-rc.2 自带 MCP 客户端。应用把工具通过独立 stdio relay 接入 Harness，工具以 `mcp__连接名称__工具名称` 暴露。只转接工具协议；每轮启动时重新发现工具，不转发服务器提供的系统指令。更改工具目录后可重新检查或发起下一轮。

启用外部服务后，服务提供的文件、网络或写入能力也可能被模型调用。请按任务需要选用服务，控制服务自身的目录和权限。应用没有为所有外部 MCP 自动建立文件沙箱。
